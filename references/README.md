# المقاطع المرجعية

هنا بتحط مقاطع صوت قصيرة (5 إلى 15 ثانية، نضيفة من غير موسيقى) عشان الموديل ياخد منها **الصوت والإحساس**.

```
references/
  أحمد-الراوي/            ← اسم الفولدر = اسم صوت مخصص هيظهر في الجدول
    default.wav           ← الصوت العادي
    default.txt           ← كلام المقطع بالظبط (VoiceTut محتاجه)
    sad.wav               ← لما الإحساس يكون "حزين"
    sad.txt
    angry.wav
    angry.txt
```

أسماء الإحساس المعتمدة: `sad` `angry` `happy` `fear` `suspense` `surprise` `calm` `whisper` `low` `loud` `slow` `fast`.

- لو مفيش مقطع للإحساس، بيستخدم `default.wav` وبعدين بيكمل بالسرعة والوقفات وعلو الصوت.
- المقاطع بتفضل على جهازك ومش بتترفع على git.
- استخدم صوتك أنت أو صوت حد وافق على كده.
