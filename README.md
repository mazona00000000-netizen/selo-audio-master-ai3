# SELO AUDIO MASTER AI

An AI-powered voiceover and podcast audio production studio focused on expressive Arabic speech, emotion-aware performance, voice control, and professional audio processing.

## Project status

Repository initialized. Application source code and Windows packaging workflow are the next build steps.

## Target platform

Windows 10 and later.

## Planned capabilities

- Script-based voiceover production with emotion and delivery cues.
- Voice and performance controls for speed, intensity, pauses, and expression.
- Audio editing and processing tools for podcast production.
- Local-first operation where supported by the selected speech engine.
- A Windows installer for straightforward desktop installation.

## Important

The speech engines and their model dependencies must be validated separately. Local engines may require additional downloads and compatible hardware.
